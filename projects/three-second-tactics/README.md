# 三秒之间

双角色预判策略对抗 Demo，单人对抗电脑。玩家为两名角色分别规划三拍动作，再在同步执行中决定是否花资源改变下一拍。

**[在线体验](https://three-second-tactics.grand-lemur-8604.chatgpt.site)** · [离线单文件版本](standalone.html)

![棋盘画面](../../docs/assets/game-board.png)

## 核心机制

| 机制 | 当前实现 |
| --- | --- |
| 规划与执行 | 每轮三拍，两名角色逐拍独立下令；双方同步行动，按移动、冲击、计分的顺序结算。正常每拍 1 秒，慢速每拍 1.8 秒。 |
| 占点与压制 | 12 × 8 棋盘，中央四个相连金格。站在金格且无横向或纵向相邻敌人，每拍 +1 分；每队每拍最多 +2 分。 |
| 移动与冲击 | 上下左右移动一格；冲击命中同一行或列、无遮挡且两格内的最近敌人，将其推开一格。冲击不直接计分，无血量系统。 |
| 防守与击退保护 | 护盾最多 2 点，防守消耗 1 点，其他动作恢复 1 点。被击退后的下一拍免疫击退；防守仍受贴身压制。 |
| 改招资源 | 初始 2 点、最多 3 点。执行中花 1 点，仅修改一名角色的下一拍；整轮未改招，结束恢复 1 点。 |
| 胜负 | 先到 10 分；最多 8 轮，结束时比分高者胜，同分为平局。 |

## 设计取舍

中央祭坛让两名角色围绕同一目标行动，缩短支援距离。贴身压制使防守与得分分开：一人保位置，另一人推开敌人，才能重新计分。护盾消耗与击退保护分别限制连续防守、连续击退，改招资源则约束执行中反复纠错。

互动教学包含占点、压制、解围三个场景。同一解围局面下，两人都防守得到 0 分；一人防守、另一人冲击得到 2 分，让分工的价值直接体现在结果里。

## 运行与验证

在线页面可直接运行。下载 `standalone.html` 后可离线打开；拆分的静态源码位于 [dist/](dist/)，入口为 `dist/index.html`，无外部依赖。

操作：鼠标点按；WASD 移动，Q 冲击，E 防守，Enter 执行。

```bash
node rules.test.cjs
node ui.test.cjs
```

规则脚本覆盖碰撞、护盾、压制、四张地图和 80 局程序检查。界面脚本在模拟 DOM 与 Canvas 环境中检查独立下令、暂停返回与教学结果；它不覆盖真实浏览器兼容性。
